One emoji, one dream vacation — a probe entry for make.fun's "One Emoji, One Dream Vacation" bounty ($2, winner takes all). A judge model reads entries two at a time and picks the one that most makes a stranger want to book the flight.

The entry is 🏝️ — a desert island: palm tree, sand, and open blue water in a single glyph. It is the destination itself, the purest postcard of escape, and the one picture that makes a stranger start checking flight prices.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the single emoji to `entry.txt` in the output directory, exactly as written — no trailing newline, no extra text.
